A LITTLE GUIDE

从第一颗音符开始

  1. 导入 MIDI。 音符、速度变化、力度与延音踏板均来自 MIDI。支持 Type 0 / 1，文件最大 20 MB。
  2. 添加相同版本的琴谱。 PDF 最大 50 MB，也支持多张 PNG / JPG / WebP 图片。只看谱时不需要 MIDI。
  3. 聆听与慢练。 拖动时间线或音符轨道定位，调整速度；在当前位置设置 A、B 后打开片段循环。
  4. 连接 MIDI 键盘。 建议桌面 Chrome 或 Edge，连接 USB 后点击连接并授权。设备自身发声时，可关闭「键盘回声」避免双重声音。
  5. 等你弹对。 选择跟练模式、声部并点击开始；按齐提示音后前进。音轨分手不准确时可在「声部分配」里调整。
  6. 让进度线跟着琴谱。 暂停并定位 MIDI 时间，点击「标记」再点击谱面的对应位置。建议逐行标记第一个和最后一个音；同一行的两个标记之间自动插值。之后点击或拖动已标记行可定位。换行、反复段落要分别标记。

本工具不做 PDF 自动识谱。跟练判断音高，不对演奏时值和力度打分。网页不会存储或分享你的文件。
